# 05 — Module Inventory

> Read-only audit 2026-11-16. Routes from `frontend/src/router.tsx`, menus from `lib/navigation.ts` / `lib/launcher.ts`,
> endpoints from `backend/routes/api.php`, roles from the default matrix in `app/Support/Rbac/Rbac.php`
> (`super_admin` has every permission and is omitted below). Roles are the **seeded defaults**; the live role
> assignments can differ (editable in *Roles & Permissions*) — **[U]** without DB access.
> UI names are English (Delivery Order, Purchase Request, Receipt); the code keeps the Indonesian/Accurate names
> (NPBG, PPB, RI).
